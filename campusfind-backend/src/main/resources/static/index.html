How CampusFind AI Works

Streamlining campus property management with neural vision and secure role-based access.

📸

1. Report with a Photo

Submit your lost or found item details with an image. The system stores the record and transmits visual features safely.

🧠

2. OpenCLIP Embeddings

The Python AI microservice extracts a 512-dimensional normalized vector using the OpenAI ViT-B-32 model.

🎯

3. Candidate Similarity Ranking

The Java backend queries active opposing reports, ranks them by cosine similarity, and displays candidate matches with match percentages.
