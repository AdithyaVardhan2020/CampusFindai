OpenCLIP Neural Matching Architecture

How CampusFind AI compares visual features without relying solely on keywords or manual tagging.

1. Image Preprocessing & Normalization

When a student uploads a photo, Pillow processes the stream, applies bicubic interpolation, and standardizes image resolution to 224×224 RGB tensors using standard CLIP normalization transforms.

2. ViT-B-32 Feature Extraction

The Python AI microservice passes the tensor through the pretrained ViT-B-32 (OpenAI weights) vision transformer encoder. The output is projected into a 512-dimensional vector and L2-normalized ($||\mathbf{v}||_2 = 1$).

3. Java Orchestration & Cosine Ranking

The Java Spring Boot backend stores the visual vector in the database. When candidate matches are requested for a report, the backend queries active opposing reports (e.g. comparing LOST with FOUND) and calls the Python rank endpoint to compute cosine similarity:

Similarity(u, v) = (u · v) / (||u|| * ||v||)

4. Human-in-the-Loop Safety Rule

Similarity scores only assist students in locating possible matches. Reports are never automatically closed or marked as resolved by the AI. Campus security and students retain full control over handover and claim verification.
